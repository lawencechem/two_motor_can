# ZE300_Pos_Home —— 双电机位置控制 · 海泰 HT-J-2E + ZE300

平台：大疆 RoboMaster **开发板 A**（STM32F427IIH）+ **CAN1**（1 MHz）。
调参用 **LinkScope**（SWD 连上后看全局变量），波形回传用 **USART2**（可选，仿 homework 工程）。

**两台电机挂在同一条 CAN1 上**，设备地址分别为 **1、2**（已用官方上位机设好，本固件**不再自动配地址**），
两台是**完全独立的轴**：各自有目标位置 / 回读 / 抱闸 / 状态机 / 参数回读 / 在线 PID，互不干扰。
收包按**回包 CAN ID = 电机自身地址(1 或 2)** 自动分拣到对应电机。

## USART2 串口（可选）：波形回传 + 指令控制
USART2 = **PD5(TX) / PD6(RX)**，**1M 波特率，8N1**，接 USB-TTL 到电脑，用 VOFA+ 一个口同时做两件事：

**上行波形（VOFA+ JustFloat 协议）**：约 50Hz，帧 = **28×float 小端 + 帧尾 `00 00 80 7F`**。

| 通道 | 内容 |
|---|---|
| 1 / 2 / 3 | 电机1 目标角° / 实际角° / 速度rpm |
| 4 / 5 / 6 | 电机2 目标角° / 实际角° / 速度rpm |
| 7 / 8 | 串口收到字节数 / 已执行指令条数（发指令没反应时看它涨不涨） |
| 9 / 10 | 电机1 / 电机2 状态机 st（0空闲 1送保持 2松闸 3运动 4到位） |
| 11 / 12 | 电机1 / 电机2 抱闸（1=合 0=松） |
| 13 / 14 | 电机1 / 电机2 驱动器运行模式（0关闭 1电压 2电流 3速度 4位置，**位置模式应为 4**） |
| 15 / 16 | 电机1 / 电机2 驱动器故障码（**0 = 正常**，非 0 说明驱动器有故障不肯动） |
| 17 / 18 | 电机1 / 电机2 驱动器**母线电压(V)**——看两台同时启动时电压有没有被拉垮 |
| 19 / 20 | 电机1 / 电机2 **驱动器回读的抱闸开关状态**（0断开 1闭合，**255=还没读到**）——确认抱闸命令真的执行了 |
| 21 / 22 | 电机1 / 电机2 对 **0xCE(抱闸)** 的应答条数——不涨 = 抱闸命令没到 / 驱动没理 |
| 23 / 24 | 电机1 / 电机2 对 **0xDA(目标)** 的应答条数——不涨 = 目标命令没到 / 驱动没理 |
| 25 / 26 | 全局 CAN **发送被丢弃**帧数 / **StdId 对不上**的收包数 |
| 27 / 28 | CAN **发送错误计数 TEC**（**255 = BUS-OFF**，那时所有帧都发不出去）/ 接收错误计数 REC |

→ VOFA+ 里选协议 **JustFloat** 即可出曲线（通道数自动识别）；因为是二进制，**不会把收到的数据当文本堆进发送框**。
**想知道"两台是不是同时启动"，看 9/10 和 11/12**：两条曲线应该在同一点一起跳变。

**下行指令（在 VOFA+ 输入框输入，点“发送”按钮或 Ctrl+Enter 发出；只按回车可能只是换行、并不发送）**：

**一条指令同时控制两台**，格式 = `电机1角度 电机2角度`（两个数值，空格或逗号分隔，单位**度**、**绝对位置**、**相对各自零点**，限 ±180）：

| 输入 | 作用 |
|---|---|
| `30 -45` | 电机1转到 30°，电机2转到 -45°（同时下发） |
| `30, -45` | 同上，逗号分隔也行 |
| `0 0` | 两台一起回各自的 0 点 |
| `m1 30` | **只动电机1** 去 30°，电机2不动（排查用） |
| `m2 -45` | **只动电机2** 去 -45°，电机1不动（排查用） |

> 与 LinkScope 写 `g1_pos_cmd_deg / g2_pos_cmd_deg` 是同一套逻辑：**立即执行**——空闲时走完整时序（保持→松闸→运动），运动中则**立刻改目标、直接改向**（不排队、不等旧运动跑完），所以两条指令同时下发时两台是同时响应的。

## 上电行为
1. **原点**（每台电机一个独立的 STM32 flash 标记）：
   - 本固件**首次**上电：把该电机当前位置记成 0 点（`0xB1`，ZE300 断电保存），并写标记；
   - 之后每次上电：该电机 `0xC4` 自动回自己的 0 点（两台先后回，每台最多等 ~2.5s，没接电机会自动跳过）。
2. 设梯形加减速 / 限速 / 限流（宏，可改）。
3. 就绪后两台都停在各自 0 点，等你在 LinkScope 里给目标（默认不做自动随机）。

| `gN_accel_rpmps` | **可写**：该电机梯形加速度 rpm/s（0xD0） | ✓ 改加速度上限 |

| `g_can_tec` / `g_can_rec` / `g_can_esr` / `g_can_err` | 只读：CAN 发送错误计数 TEC（**>127 错误被动，255 = BUS-OFF，那时什么帧都发不出去**）/ 接收错误计数 / ESR 原始值 / HAL 错误码 | ✓ 排查通信 |
| `gN_cur_pos_kp/ki`、`gN_cur_vel_kp/ki`、`gN_cur_pos_lim_rpm`、`gN_cur_vel_lim_A` | **只读**：该电机驱动当前实际那 6 个值 | ✓ |
| `g_run_ms` | 开机运行毫秒（两机共用时间轴） | ✓(时间轴) |

### 在线调 PID（不用串口，用 LinkScope 写变量，每台独立）
1. 上电后等约 1~2s，`gN_pid_pos_kp/ki/vel_kp/ki` 会自动变成**该电机驱动的当前值**（安全起点，不会误覆盖成 0）；
2. 在 LinkScope 里**双击直接改**某台某个 pid 变量的值（例如位置环 Kp 调小来止震）；
3. 程序每 300ms 轮询，检测到不一致就把新值写进**对应那台**驱动（0xB6~0xB9，float），写完后回读对齐；
4. 看该台 `gN_now_deg / gN_tgt_deg / gN_spd_rpm` 的反应再改下一个参数。
   - 想单独动 1 号 → 改 `g1_pos_cmd_deg`；想单独动 2 号 → 改 `g2_pos_cmd_deg`；想让两台一起去同一位置 → 把两个目标写成相同值。
   - PID 同样各调各的：改 `g1_pid_pos_kp` 只作用于地址1那台。

> **速度/加速度上限不是 PID**：位置模式速度上限 = `gN_pid_pos_lim_rpm`（rpm，0xB2）；
> 梯形加速度/减速度 = `gN_accel_rpmps` / `gN_decel_rpmps`（rpm/s，0xD0/D1），都是**每台独立可写**的。
> 写进去后看回读 `gN_cfg_vmax_x100`（×0.01rpm）、`gN_cfg_acc_x100`/`gN_cfg_dec_x100`（×0.01rpm/s）确认驱动已接受。
> PID（位置/速度环）决定的是"**跟不跟得上**你设的速度/加速度包络"（震荡、误差、超调）；电流上限 `gN_pid_vel_lim_A`（0xB3）
> 决定电机实际有没有足够力矩达到上限——上限设得再高，PID 软或限流小也到不了。用 `gN_spd_rpm`/`gN_peak_rpm` 看真实速度有没有顶到你设的上限。

> 提示：这些 PID **断电不保存**，每次上电从驱动默认开始。方向感：到位震荡大→**位置环 Kp 调小**；有稳态误差/慢爬→适当加 Ki；速度跟不平→调速度环 Kp/Ki。

> 状态量都是全局且 `volatile`，每主循环(5ms)刷新；编译已开 Debug 信息。

## 还没接电机 / 只接了一台时的表现（只上电）
发目标后若该电机一直没有任何 CAN 回包，3 s（`NO_ACK_TIMEOUT_MS`）判定"没接电机"，状态回空闲。
此时你会看到：**接上的那台** `gN_now_cnt` 会动、`gN_rx_cnt` 增长；**没接的那台** `gN_rx_cnt` 停在 0，
`gN_st` 在 0~4 之间循环。两台互不影响。

## 编译烧录
1. Keil 打开 `MDK-ARM\test_feedback.uvprojx`（STM32F427IIH，AC5）。
2. F7 编译（应 0 错误 0 警告），产物 `MDK-ARM\test_feedback\test_feedback.hex`。
3. SWD 烧录 → 上电 → LinkScope 连接后把上面变量拉曲线。
   - **第一次烧本版建议用 "Erase Full Chip"**：本版改用了新的 flash 魔数（每台各一个标记字），
     全片擦后首次上电会把**两台电机的当前位置都设成 0 点**（若两台已按安装位置就位，这就是你要的零点）。
   - 之后普通烧录即可，两台会各自回上次定的 0 点。

## 关键宏（`Core/Src/main.c` 顶部）
- `MOT1_ADDR=1 / MOT2_ADDR=2` 两台设备地址；`MOT_COUNT=2`；
- `AUTO_INTERVAL_MS`=2000 给位置间隔；`AUTO_RANGE_DEG`=180 随机范围；
- `ACCEL_RPMPS/DECEL_RPMPS`=150 梯形加/减速度（0xD0/D1；HT6010输出上限~93rpm，太大起停会震）；
- `POS_MAX_RPM`=90 位置模式最大速度(0xB2)（本型号减速36:1，输出最高~93rpm，设更大无效）；
- `IQ_LIMIT_A`=8.8 **位置/速度模式最大电流 A(0xB3)**（HT6010额定8.8A；短时可放宽到12，别长期超）；
- `HOLD_ZERO_MS`=5000 **上电回零到位后先在 0 点保持 5s** 再进入自动随机（默认随机关，改 `gN_auto`=1 才开）；
- `SETTLE_TOL_CNT`=16 到位容差(≈0.35°)；`NO_ACK_TIMEOUT_MS`=3000 无回包判定；
- `ARRIVE_MAX_MS`=30000 有反馈但久不到位兜底。

## 提醒
- **对同一台驱动器的两帧之间强制隔开 1ms**（`g_dbg_frame_gap`，默认 1）。原因：官方 Demo 注释
  与本项目实测都表明"连发多条命令时驱动器只认第一条"。主循环里对一台电机可能在同一拍内连续下发
  参数/查询/目标/抱闸好几帧，挤在一起时后面的会被驱动忽略——这正是"两台一起发只有一台动"的根因。
  运动中"重发目标"和"保持松闸"也改成**错开**下发（不再同一拍连发两帧）。

### 对比实验：两个运行时开关（烧一次就能做，不用重编译）
在线改这两个变量，**下一拍即生效**，用来确认根因到底是哪一处。做完记得改回默认值。

| 变量 | 默认 | 含义 |
|---|---|---|
| `g_dbg_frame_gap` | `1` | 同一台驱动器相邻两帧最小间隔(ms)。改 **0** = 恢复"挤在一起连发"的老写法 |
| `g_dbg_burst_ce` | `0` | 改 **1** = 恢复"0xDA 目标 与 0xCE 松闸 同一拍连发"的老写法 |

| `g_dbg_frame_gap` | `g_dbg_burst_ce` | 预期现象 |
|---|---|---|
| 1 | 0 | **正常**：`30 -45` 两台同时动（当前值） |
| 0 | 0 | 若故障复发 → 说明**帧间隔**是决定性的 |
| 1 | 1 | 若故障复发 → 说明**0xDA/0xCE 同拍连发**是决定性的 |
| 0 | 1 | 两项都退回老写法，应最接近最初的故障现象 |
- 若某台电机**该动时不动**，按这个顺序看：`gN_tx_fail`（帧发出去了吗）→ `gN_rx_da` / `gN_rx_ce`
  （驱动回了吗）→ `gN_brk_sw`（抱闸命令执行了吗）→ `gN_run_mode` / `gN_fault`（驱动肯干吗）→
  `gN_bus_v`（电压够吗）→ `g_can_tec`（总线 BUS-OFF 了吗）。
- **LinkScope 一连接就报 `Failed to read memory at 0x5a5a5a03`**（watch 表是空的也报）：
  `0x5A5A5A03` = 旧 flash 魔数 `PERSIST_MAGIC(0x5A5A5A02)` **+ 1**。原因是：
  1. ARMCC 会把**每个 `#define` 的名字和字面值**原样写进 `.debug_macinfo`（宏调试信息，本工程该节约 1.4 MB），
     记录就是纯文本 `PERSIST_MAGIC (0x5A5A5A02u)`；
  2. LinkScope 连接时扫描该节里所有 `0x????????` 形式的字面值，把 **值+1 当成变量地址**去读；
  3. 落在存储映射里的（`0x08xxxxxx` flash / `0x20xxxxxx` RAM / `0x40xxxxxx` 外设）都读得通所以不出声，
     **只有这个魔数掉在映射外**——所以 181 个常量里偏偏它一个人报错。
  **换数值没用**（换到哪它就跟到哪，实测换成 `0x1F2E3D4C` 后报 `0x1f2e3d4d`）；要让这个值**别再以宏字面值的形式
  进调试信息**。现已把 `PERSIST_MAGIC` 从 `#define` 改成 `static const uint32_t`（取值 `0x0801C0DE`，故意落在
  flash 窗口内做双保险）。**别再改回 `#define`。**
  副作用：魔数变了 = 两台被当成"第一次上电"，各自把当前位置重新记成 0 点。
- 两台机械上若需要**同步同动**：本版按"完全独立"实现，把两个 `gN_pos_cmd_deg` 设成相同值即可；若要做自动防卡滞的硬同步，属另一个需求。
- 重物正式跑前用官方上位机把 **最大电流(0xB3)** 限好，先小角度小加减速试；
- 想重设某台 0 点：用 "Erase Full Chip" 重新烧一次，或把 `Core/Src/main.c` 里对应 flash 标记字
  （`PERSIST_ADDR_M1`=0x08010000 电机1 / `PERSIST_ADDR_M2`=0x08010004 电机2）擦掉再上电；
- 垂直重物：电机没接/刹车时序没验证前别挂负载；`gN_brk` 到 1(合闸)后负载才安全。
